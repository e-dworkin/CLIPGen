# UCIe Advanced Package — 16-Column x64 Bump Map (16 GT/s Implementation)
# Source: UCIe Specification Revision 2.0, Figure 5-25
#
# Recommended bump pitch: 25–30 um (12 GT/s), 31–37 um (16 GT/s)
# Module depth at 25 um pitch: ~400 um
# Note: Rows 1 and 31 required for packaging solutions using floating bridges
#       without TSVs; optional for packaging solutions with TSVs.
#
# Grid : 31 rows x 16 columns = 496 bumps total
# Counts:
#   tx    : 64  (txdata0-63, txdataRD0)
#   rx    : 64  (rxdata0-63, rxdataRD0)
#   vdd   : 48  (VCCIO / VCCFWDIO)
#   vss   : 176 (VSS)
#   other : 16  (sideband: txdatasBRD, rxdatasBRD, txcksb, rxcksb,
#                Txckp, Txckn, Rxckp, Rxckn, Txvld, Txtrk, Rxvld, Rxtrk,
#                txckRD, rxckRD, txck, rxck)
#   empty : 128
#
# Row 0 is farthest from die edge; Row 30 is at die edge.
# Left half (col 0-7): TX data;  Right half (col 8-15): RX data.
# Even data rows carry 8 tx + 8 rx (dense packing, no alternating).
