# UCIe Advanced Package — 16-Column x32 Bump Map
# Source: UCIe 1.0 Specification, Figure 5-28
#
# Recommended bump pitch: 25–30 um (12 GT/s), 31–37 um (16 GT/s)
# Module depth at 25 um pitch: ~237.5 um
#
# Grid : 10 rows x 16 columns = 160 bumps total
# Counts:
#   tx    : 32  (txdata0-31, txdataRD0)
#   rx    : 32  (rxdata0-31, rxdataRD0)
#   vdd   : 16  (VCCIO / VCCFWDIO)
#   vss   : 44  (VSS)
#   other : 12  (rxcksBRD, txdatasBRD, rcksb, txdatasb,
#                txckp, txckn, rxckp, rxckn, txtrk, txvld, rxvld, rxtrk)
#   empty : 24
#
# Row 0 is farthest from die edge; Row 9 is at die edge.
# Left half (col 0-7): TX side;  Right half (col 8-15): RX side.
#
#         Col0  Col1  Col2  Col3  Col4  Col5  Col6  Col7  Col8  Col9  C10   C11   C12   C13   C14   C15
#         --------------------------------------------------------------------------------------------
