# UCIe Advanced Package — 8-Column x64 Bump Map (32 GT/s Implementation)
# Source: UCIe Specification Revision 2.0, Figure 5-26
#
# Recommended bump pitch: 51–55 um (32 GT/s)
# Module depth at 55 um pitch: ~1705 um (approx)
# Note: Rows 1, 2, and 61 required for packaging solutions using floating bridges
#       without TSVs; optional for packaging solutions with TSVs.
#
# Grid : 39 rows x 8 columns = 312 bumps total
# Counts:
#   tx    : 64  (txdata0-63)
#   rx    : 64  (rxdata0-63)
#   vdd   : 64  (VCCIO / VCCFWDIO)
#   vss   : 116 (VSS)
#   other : 12  (rxcksBRD, txdatasBRD, rcksb, txdatasb,
#                txckp, txckn, rxckp, rxckn,
#                Txvld, Txtrk, Rxvld, Rxtrk)
#   empty : 56
#
# Row 0 is farthest from die edge; Row 38 is at die edge.
# Left half (col 0-3): TX data;  Right half (col 4-7): RX data.
# Each data row carries 4 TX + 4 RX lanes (dense packing).
#
#         Col0  Col1  Col2  Col3  Col4  Col5  Col6  Col7
#         ------------------------------------------------
vss  vss  vss  vss  vss  vss  vss  vss   # R00: VSS (bridge row)
