# UCIe Advanced Package — 10-Column x64 Bump Map (32 GT/s Implementation)
# Source: UCIe Specification Revision 2.0, Figure 5-24
#
# Recommended bump pitch: 38–44 um (24 GT/s), 45–50 um (32 GT/s)
# Module depth at 45 um pitch: ~1125 um (approx)
# Note: Rows 1, 2, and 53 required for packaging solutions using floating bridges
#       without TSVs; optional for packaging solutions with TSVs.
#
# Grid : 53 rows x 10 columns = 530 bumps total
# Counts:
#   tx    : 64  (txdata0-63)
#   rx    : 64  (rxdata0-63)
#   vdd   : 60  (VCCIO / VCCFWDIO)
#   vss   : 196 (VSS)
#   other : 14  (txdatasBRD, rxdatasBRD, txcksb, rxcksb,
#                Txckp, Txckn, Rxckp, Rxckn, tckRD, rckRD,
#                Txvld, Txtrk, Rxvld, Rxtrk)
#   empty : 192
#
# Row 0 is farthest from die edge; Row 52 is at die edge.
# Left half (col 0-4): TX side;  Right half (col 5-9): RX side.
# Each data row carries 4 TX + 4 RX lanes.
