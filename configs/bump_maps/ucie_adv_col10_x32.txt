# UCIe Advanced Package — 10-Column x32 Bump Map
# Source: UCIe 1.0 Specification, Figure 5-27
#
# Recommended bump pitch: 38–44 um (24 GT/s), 45–50 um (32 GT/s)
# Module depth at 45 um pitch: ~680.5 um
# Note: Rows 1, 2, and 53 required for packaging solutions using floating bridges
#       without TSVs; optional for packaging solutions with TSVs.
#
# Grid : 26 rows x 10 columns = 260 bumps total
# Counts:
#   tx    : 32  (txdata0-31, txdataRD0)
#   rx    : 32  (rxdata0-31, rxdataRD0)
#   vdd   : 30  (VCCIO / VCCFWDIO)
#   vss   : 104 (VSS)
#   other : 14  (txdatasBRD, rxdatasBRD, txcksb, rxcksb,
#                Txckp, Txckn, Rxckp, Rxckn, tckRD, rckRD,
#                Txvld, Txtrk, Rxvld, Rxtrk)
#   empty : 80
#
# Row 0 is farthest from die edge; Row 25 is at die edge.
# Left half (col 0-4): TX side;  Right half (col 5-9): RX side.
# Each data row carries 4 TX + 4 RX lanes (2 empty/power per side).
#
#         Col0  Col1  Col2  Col3  Col4  Col5  Col6  Col7  Col8  Col9
#         -----------------------------------------------------------
